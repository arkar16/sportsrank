# Men's Division I basketball, 1980–81 through 1982–83

Each row in `teams.csv` records one program's conference for that season. Each row in `results.csv` records one game between two season members. Day zero is October 31 of the starting calendar year. H, A and N give the site from the winner's perspective. Program IDs follow the March Mania directory. Baltimore (10001), West Chester State (10002) and Catholic (10003) have SportsRank IDs because they left Division I before the directory begins.

The dated results and both postseason fields come from John Trono's archive. Postseason dates were matched on season, tournament, both teams and both scores against the pinned game histories. The NCAA brackets and school records supply unmatched dates. Where sources disagree on a score, these files retain the score archive's result unless the listed corrections apply. - Connecticut beat Army 81–60 at its Hartford home court on December 29, 1980. James Madison beat Georgetown 61–55 on March 12, 1981. [Rutgers results](https://scarletknights.com/documents/download/2026/10/28/Rutgers_MBB_2026-27_Media_Guide_FINAL.pdf) · [South Florida results](https://gousfbulls.com/documents/download/2026/10/27/2026-27_USF_MBB_MG__RECORDS_HISTORY__-_WEB.pdf)
