# Frozen Codex Workflow records

The six Markdown state documents here were moved byte-for-byte from
`agent_docs/` during the 2026-09-10 migration. They preserve acceptance reports,
hashes, lessons, and historical context. They are no longer maintained startup
instructions or current status. Repository-relative paths in their original
text are interpreted from the repository root; external and `/tmp` paths may
no longer exist. Old PR states and instructions are historical reports.

`original-agent-instructions.md` preserves the formerly ignored root entry
point. `installation-state.json` and `personalization.md` preserve the removed
project-local workflow metadata. None of these archived files activates the
workflow or overrides current instructions.

Use [current work](../../../work/current.md) to restart and
[the evidence index](../../../evidence/2026-gate1.md) for targeted provenance.
The migration supersedes the orchestration requirement through
[ADR-0015](../../../adr/0015-separate-project-knowledge-from-agent-orchestration.md).
