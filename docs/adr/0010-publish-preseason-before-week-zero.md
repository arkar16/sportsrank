# Publish PRESEASON before Week 0

SportsRank will publish a distinct PRESEASON CORS Ranking, initialized from the prior Season's FINAL through the provisional `1.75` Season Carryover adjustment, and use it for the Week 0 slate and spreads. Week 0 is a normal competition week, so W0 is calculated only after completed Week 0 games; this corrected lifecycle applies to rebuilt Seasons from 2024 onward while older public pages remain frozen until a separate migration is approved.
