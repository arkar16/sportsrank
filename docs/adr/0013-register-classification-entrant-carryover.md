# Register Classification Entrants before Season Carryover

When a team newly enters FBS and therefore has no FBS FINAL in the preceding Season, SportsRank will reconcile it only through an exact, authoritative, source-cited Classification Entrant record. The entrant receives the existing explicit FCS CORS baseline of `-10` and zero prior wins-vs-expected, and the Release seals the adjustment and source as carryover provenance. Arbitrary missing, extra, renamed, or returning teams remain hard errors. This keeps the P0 backfill runnable across real Classification changes without restoring the silent missing-team fallback or prematurely implementing cross-Classification calibration.
