# Give every ranked program a permanent history

A school's appearance in any archived CORS Ranking establishes its program
history, even if it left the classification long ago or is missing from today's
CFBD catalog. A documented rename belongs to the same program. Distinct schools
keep separate pages. Archive membership and numerical results govern the history.

Use the school mark the provider supplies today across seasons. Retain the
catalog once and share local image assets across releases so an archive visit
or a cached rebuild never has to consult the provider. A missing image leaves
the school's written name and history available.
