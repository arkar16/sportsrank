# Domain documentation

SportsRank is a single-context repository. Read root `CONTEXT.md` when exploring
or changing domain behavior; use its canonical terms. `docs/adr/README.md`
routes to relevant decisions. Read the affected ADRs before proposing a change
to their contracts, and identify proposed conflicts explicitly.

Use the installed domain-modeling skill when sharpening language or recording
decisions. The glossary contains meanings; specs contain requested behavior;
ADRs retain consequential trade-offs. Document ownership and lifecycle are in
`docs/agents/project-memory.md`.
